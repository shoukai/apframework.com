# SEO 与 GEO 改进 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 改进文章主题发现、页面收录信号、站内阅读路径和社交分享素材。

**Architecture:** 内容源使用统一标签，标签页按文章数量控制索引并为核心主题提供导读。文章页在现有导航外增加相关内容，近期文章使用内容相关的本地图像。输出页面清单供 Search Console 人工核对。

**Tech Stack:** Next.js 15 App Router、Contentlayer2、MDX、TypeScript、Sharp。

**Spec:** `docs/superpowers/specs/2026-11-01-seo-geo.md`

## Global Constraints

- 保留所有现有文章 URL 和未提交变更。
- 不将未经验证的推断写成本站实测。
- sitemap 只包含希望搜索引擎收录的规范 URL。
